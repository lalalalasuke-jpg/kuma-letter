# 書き方:
#   *名前              場面の目印（ジャンプ先）
#   くま「せりふ」       話す人とせりふ
#   ふつうの文          地の文（ナレーション）
#   - 選択肢 -> 行き先 ? 条件   選択肢（続けて並べると1つのメニューになる。「? 条件」は無くてもよい）
#   @bg 背景名 [rain|dark]   背景（rain を付けると雨＋暗く、dark は暗くするだけ）
#   @ch キャラ キャラ    立ち絵（1人なら真ん中、2人なら左右。@ch - で消す）
#   @set 名前 / @add 名前   フラグを立てる / 数を1増やす
#   @if 条件 -> 行き先   条件に合えばジャンプ
#   @goto 行き先 / @end エンディング名
#   せりふの中の \n で改行
# 条件: tv>=3 / umbrella / !umbrella / a & b（どちらも）/ a | b（どちらか）
